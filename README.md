# Retina.blog V1

A polished Next.js editorial publication prototype for retina.blog.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Included in V1
- Publication-style homepage
- Six topic hubs
- Data-driven article pages
- Evidence-status UI and editorial standards
- Responsive desktop/mobile layout
- SEO metadata foundation
- Newsletter placeholder
- About and Editorial Standards pages
- Local sample launch content

## OpenHands improvement brief
1. Connect a production CMS (Sanity, Payload, Contentful, or equivalent) while preserving the research-aware content model.
2. Add fields for primary/secondary SEO keywords, search intent, DOI, PMID, study type, peer-review status, evidence level, limitations, reviewer, last evidence review, and source links.
3. Implement Article, BreadcrumbList, Organization/NewsMediaOrganization, ProfilePage, and appropriate scholarly/medical structured data.
4. Replace placeholder retinal illustrations with licensed scientific imagery or intentionally generated/editorial graphics.
5. Connect the Retina Brief form to an email platform.
6. Add site search, sitemap, robots.txt, canonical URLs, Open Graph images, analytics and consent handling.
7. Expand to the planned 25–30 article launch library with evidence-backed sources and internal links.
8. Add author/reviewer profile pages and visible correction/update history.
9. Add accessibility and performance QA and preserve the restrained editorial visual system.
10. Do not convert the site into a generic medical template or text-heavy SEO farm.

## Editorial principles
- See What's Next.
- Evidence first. Interpretation second. Hype last.
- SEO guides topic selection; evidence governs claims.
- Retina.blog is editorial/educational content, not individual medical advice.
